## 原因与修复

原平台账号目录由静态目录及旧系统自定义账号组成，迁移后的账号表漏了 5 个账号，大部分账号创建日期未导入。原平台审核次数还会回退到目录数据，累计提款包含目录中的导入累计值。新项目此前没有完整保留这些来源与优先级。

收款统计改为对照原服务 PaypalActivity：规范订单和规范订单日期之后的历史日数据合并去重，保留原状态范围与汇率口径。余额沿用原系统余额记录、收款基线及提款基线，提款区分导入累计、历史手工记录和迁移后新流水，避免重复计算。日期边界按原上海时区处理。

新增只补齐目录的可重复执行命令：

```text
php artisan paypal:restore-legacy-catalog <原账号目录 JSON 路径> --apply
```

本地执行补齐 5 个账号和 261 个日期（包含新增账号），共 263 个账号均有创建日期。没有覆盖余额流水、提款流水或 RBAC 数据。首次恢复遇到新项目已有 PayPal 业务操作时拒绝覆盖；已恢复目录校验来源指纹并保留流水分界。
